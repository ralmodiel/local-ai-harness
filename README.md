# Local AI from a Hardware Stash

A mini PC (Ryzen AI 9 HX 470: Radeon 890M iGPU + XDNA2 NPU), an RTX 5060 Ti over OCuLink, a Radeon RX 7600 over USB4
and two NVMe drives, combined into one local AI stack for coding-assistant work, with every model measured for speed
and quality on a real codebase.
